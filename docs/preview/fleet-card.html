Fleet Overview — 機器卡片預覽

一台機器一張卡。名稱下面是 project（service_namespace）。Memory / Space 下面是「已用 / 總量」，單位自動換（B / KB / MB / GB / TB，1024 進位）。 門檻只畫成長條上的兩條刻度；滑過某一列看數值，按 ✎ 看是這台自己的還是 default。

Machines
OK ≥ warn ≥ crit / DOWN │ 刻度 = warn / crit

假想情境：DOWN、剛開機、名稱很長、標籤很多

線上的機器沒有這些情況，這裡用假資料看版面。標籤只排一行，放不下的收成「+N」，點一下展開。 註：現在機器只有 project 一個有意義的標籤，agent 也沒有加其他標籤的設定；這組是看「萬一以後加了」會不會撐爆。

對照：同一台機器現在的樣子（4 張卡）

現在每張卡看得到的標籤固定是 3 個：instance（= 卡片名稱）、job（機器一律是 node）、service_namespace（project）。
